# Klavye Altındaki Kırıntıların Parlamentosu

**Resmi bildiri:** Bu yazılım, klavye tuşlarının altına düşmüş ekmek, simit, cips ve kuru üzüm kırıntılarının yasama organıdır. Üyeler yemin etmez; düşer. Toz Komisyonu veto hakkını elinde tutar. Temizlik günü anayasa ihlalidir.

Patates yoktur. Olmayacaktır. Bu konu kapalıdır.

## Neden vardır?

Çünkü F tuşunun altında bir hukuk boşluğu vardı. Biz doldurduk. İçerikle değil, tutanakla.

## Kurulum

```bash
python3 parlamento.py
```

Bağımlılık: Python 3 ve bir miktar kırıntı. Pip yok. Pipet de yok.
